# Company & University Logos

Download these logos manually and save them in this folder.

The website is set up to gracefully fall back to text names if logos aren't present.

## Required Files

### Companies
| Filename | Source | Notes |
|----------|--------|-------|
| `ada.png` | https://www.ada.cx/ | Check their press kit or right-click save from site |
| `omilia.png` | https://omilia.com/ | Check their press/media page |

### Universities

## Quick Download Links

1. **Aristotle University** - https://www.auth.gr/en/auth-logo-en/
   - Official logo page with PNG downloads (72ppi and 300ppi versions)
   
2. **University of Plymouth** - Search for "University of Plymouth brand guidelines"
   - Or save from their website header
   
3. **University of Naples Federico II** - https://www.unina.it/
   - Save logo from site header or find press kit

4. **Ada** - https://www.ada.cx/
   - Right-click and save logo from site header
   
5. **Omilia** - https://omilia.com/
   - Right-click and save logo from site header

## Recommended Specs

- **Format:** PNG with transparent background
- **Height:** 40-50px (will be displayed at max-height: 40px)
- **Color:** Logos will be displayed in grayscale, full color on hover
- **Naming:** Use lowercase filenames exactly as listed above
